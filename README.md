# Canon LBP6000 CAPT Docker Print Server 🖨️

Цей проект дозволяє запустити легендарний принтер **Canon LBP6000 (LBP6018)** у сучасному Linux-середовищі (Debian 12+, Ubuntu 22.04+, Home Assistant OS) за допомогою Docker.

Він вирішує проблему застарілих 32-бітних драйверів Canon CAPT, які конфліктують із новими системними бібліотеками.

---

## 📂 Структура проекту

Для успішної збірки папка повинна містити:

- `Dockerfile` — образ на базі Debian Bookworm i386  
- `docker-compose.yml` — конфігурація запуску  
- `cndrvcups-common_3.20-1_amd64.deb` — спільні компоненти драйвера  
- `cndrvcups-capt_2.70-1_amd64.deb` — драйвер CAPT  

---

## 🛠 Крок 1: Підготовка хост-системи (Linux)

Перед запуском Docker необхідно звільнити ресурси, які він буде використовувати.

### 1. Зупиніть локальний CUPS

```bash
sudo systemctl stop cups
sudo systemctl disable cups
```

### 2. Вбийте залишкові процеси драйвера

```bash
sudo pkill -9 ccpd
sudo pkill -9 captfilter
```

### 3. Перевірте USB-підключення

```bash
ls /dev/usb/lp0
```

Команда повинна показувати пристрій.

---

## 🚀 Крок 2: Збірка та запуск

### 1. Перейдіть у папку з проектом

```bash
cd /opt/capt-lbp6000
```

### 2. Запустіть контейнер

```bash
docker compose up -d --build
```

### 3. Перевірка працездатності

```bash
docker exec -it lbp6000-server /etc/init.d/ccpd status
```

Ви маєте побачити два числа PID. Якщо їх немає — принтер не ініціалізувався.

---

## 💻 Крок 3: Підключення клієнтів

Принтер доступний за адресою:

```
http://<IP_ВАШОГО_СЕРВЕРА>:631/printers/LBP6000
```

---

### 🔹 Windows

1. Відкрийте: **Параметри → Принтери та сканери → Додати пристрій**
2. Натисніть: **"Необхідного принтера немає в списку"**
3. Оберіть: **"Вибрати спільний принтер за назвою"**
4. Вставте URL:

```
http://<IP_СЕРВЕРА>:631/printers/LBP6000
```

5. Драйвер:
   - `Generic → MS Publisher Imagesetter`

---

### 🔹 Linux (Ubuntu / Mint / Arch)

Система повинна знайти принтер автоматично через Avahi / Bonjour.

Якщо ні:

1. Відкрийте **Налаштування принтерів**
2. Додайте новий принтер вручну
3. Вкажіть шлях:

```
ipp://<IP_СЕРВЕРА>:631/printers/LBP6000
```
